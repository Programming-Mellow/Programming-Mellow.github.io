Projects

Vikings Win Predictor

Gives a win probability for every Minnesota Vikings game, or any NFL team's, from XGBoost models trained on each NFL game since 2010, with SHAP factors showing what pushed the number up or down. On 569 games from the 2024 and 2025 seasons that the models never saw, the version that takes the Vegas line as an input tied Vegas on log loss (0.598), and the stats-only version picked 65% of winners. A Claude assistant answers questions about each game by calling the prediction API through an MCP server, so every probability it quotes is pulled from the trained model.

Stack: Python, XGBoost, scikit-learn, SHAP, Polars, MLflow, FastAPI, Streamlit, Claude API, MCP, Docker, GitHub Actions, pytest

Vikings Win Predictor repository on GitHub

Self-hosted AI assistant

A private LLM setup built with LM Studio and Open WebUI, so my data and conversations stay under my control. I added RAG pipelines with embedding models and vector search for retrieval from my own documents, along with web search for questions the local model can't answer alone. Tailscale lets me reach it from anywhere without exposing any service to the public internet.

Stack: LM Studio, Open WebUI, embedding models, vector search, Tailscale

Bedrock FAQ assistant

A chatbot on Amazon Bedrock that answers questions from a set of documentation using retrieval-augmented generation. Bedrock Knowledge Bases backed by OpenSearch Serverless handle the semantic search over the documents. I configured Guardrails to filter content and added CloudWatch logging for compliance monitoring.

Stack: Amazon Bedrock, Bedrock Knowledge Bases, OpenSearch Serverless, Bedrock Guardrails, CloudWatch

WiNDY

A Discord bot that sends me a briefing every morning with tasks pulled from several Notion dashboards, the weather, and news articles chosen by a scikit-learn classifier trained on articles I labeled. At the end of each day it clears finished tasks out of Notion. It runs in Docker on my Raspberry Pi.

Stack: Python, discord.py, Notion API, scikit-learn, SQLite, feedparser, APScheduler, Docker

WiNDY repository on GitHub

Daily news digest

A small script that reads RSS feeds on AI, cloud, and DevOps, asks Claude to keep only the articles that match my reading profile and summarize why each one matters, then adds the day's digest to a Notion gallery. Cron runs it every morning on the Raspberry Pi. A GitHub Actions check confirms on every push that each feed still resolves, without calling any paid API.

Stack: Python, Claude API, Notion API, cron, GitHub Actions

Daily news digest repository on GitHub

Raspberry Pi home lab

I set up the Pi headless over RealVNC Viewer in January 2024. Since then I've used it to host a website and a Minecraft server for devices on my home network, and to run WiNDY and the news digest in the background.

Stack: Raspberry Pi OS, RealVNC, Docker, cron
